**F5 Distributed Cloud Observability** provides unified end-to-end visibility across global application traffic, infrastructure health, and security events.

## Telemetry Pipeline

```text
+-------------------------------------------------------------------------+
|                     Distributed Telemetry Data Pipeline                 |
|                                                                         |
|  Data Planes (Edge PoPs, Customer Edges, Load Balancers)                |
|        |                                                                |
|        v                                                                |
|  +-------------------------------------------------------------------+  |
|  | Telemetry Collector: Access Logs, Metrics (Prometheus), Spans    |  |
|  +---------------------------------+---------------------------------+  |
|                                    |                                    |
|                                    v                                    |
|  +-------------------------------------------------------------------+  |
|  | Stream Processing & Anomaly Analytics                             |  |
|  +---------------------------------+---------------------------------+  |
|                                    |                                    |
|         +--------------------------+--------------------------+         |
|         | Dashboards & Logs                                   | Alerts  |
|         v                                                     v         |
|  +-----------------------------+               +---------------------+  |
|  | F5 XC Console / Grafana UI  |               | Webhook, PagerDuty, |  |
|  | Distributed Trace Views     |               | SIEM Export (Splunk)|  |
|  +-----------------------------+               +---------------------+  |
+-------------------------------------------------------------------------+
```

## Core Capabilities

  <Card title="Real-Time Access Logs" icon="document">
